# Fake News Detection (NLP Classification)

Machine-learning project that classifies news articles as **Real** or **Fake** from their headline and body text, using TF-IDF features and classical classifiers. Built as an individual major project for the *Media & Publishing* domain.

## Problem
Misinformation damages public trust and can cause real-world harm. This project builds and compares text classifiers, explains which linguistic patterns separate fake from real articles, and recommends how a news platform could use the model to flag articles **before publishing**.

## Dataset
[Fake News Detection Datasets (Kaggle, `emineyetm`)](https://www.kaggle.com/datasets/emineyetm/fake-news-detection-datasets)

| Column | Description |
|---|---|
| `title` | Article headline |
| `text` | Article body |
| `subject` | Category/section |
| `date` | Publication date |
| `label` | Target: Real / Fake (added from file of origin: `True.csv` → Real, `Fake.csv` → Fake) |

**Setup:** download the dataset and place `Fake.csv` and `True.csv` inside `data/`.
`data/sample_news.csv` is a tiny **synthetic** file included only so the notebook can be smoke-tested without the download. **Do not report results from it.**

## Workflow
Data → Statistics → EDA → Preprocessing → Feature Engineering → Modeling → Evaluation → Insights → Recommendations

1. **Data understanding** – shape, dtypes, missing values, duplicates, unique values.
2. **Statistics** – mean, median, mode, min/max, variance, std, quartiles, IQR, correlation on derived length features.
3. **EDA** – class balance, subject distribution, length distributions, word frequencies, heatmaps, scatter/box plots.
4. **Preprocessing** – cleaning, de-duplication, outlier capping, target encoding, stratified train/test split.
5. **Feature engineering** – style features (caps ratio, `!`/`?` counts, quotes, title caps, etc.) and TF-IDF (uni+bi-grams).
6. **Models** – Logistic Regression, Decision Tree, Random Forest, AdaBoost, KNN.
7. **Evaluation** – accuracy, precision, recall, F1, ROC-AUC, confusion matrices, train-vs-test gap, 5-fold CV.
8. **Threshold analysis** – precision/recall trade-off and a three-band deployment policy.
9. **Interpretability** – top terms driving Fake vs Real predictions.

## Design decisions worth knowing
- **Fake = positive class**, so recall means "share of fake articles caught".
- **`subject` is not used as a model feature.** In the original data its values barely overlap between classes, so it would leak the label.
- **News-agency datelines (e.g. "CITY (Reuters) -") are stripped**, and the notebook measures how much they inflate scores (Section 9).
- **TF-IDF is fitted on the training split only** to avoid leakage.

## Limitations
Text-only signals; mostly US-politics data from a narrow time window (topic/time drift); possible publisher artefacts; satire and opinion pieces; adversarial rewriting. Suggested extensions: source credibility, publication date/time, author history, social-sharing signals, fact-checking against trusted sources.
